# 상상네컷

PRD 1.0에 따른 교실용 스티커 네컷 포토부스의 첫 버전입니다. 사진을 촬영하거나 불러온 뒤 MediaPipe SelfieSegmenter로 인물 영역을 오려 미리 준비한 배경에 배치합니다.

## 실행

Node.js 22 이상에서 추가 패키지 설치 없이 실행할 수 있습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 다른 기기에서는 HTTPS 호스팅이 필요합니다. `dist/`가 정적 배포 디렉터리입니다. 파일을 더블클릭하는 `file://` 방식은 모델 Worker를 실행할 수 없습니다.

## 구현한 기능

- 자체 제작 장면 배경 8종, 배경 업로드·맞춤·전체 컷 적용
- 일반 카메라·전후면 전환, 3초/5초 타이머, 연속 촬영·중단
- 사진 불러오기와 Worker에서 실행하는 실제 인물 분할
- 컷별 인물 최대 3개, 이동·크기·회전·겹침 순서·복제·다른 컷에 복사
- 재촬영·원본 모드·가장자리 부드러움·테두리·장식
- 2·3·4컷, 사진 순서 변경과 인물·컷 교체 선택
- 인물 경계 복원·지우기 브러시와 수업 준비 상태 점검
- 최근 20단계 실행 취소·다시 실행
- 세로 1440×4400, 2×2 2800×2480 PNG와 작은 크기 대체 저장
- 교사 포즈 미션·타이머·배경 변경 잠금·학교 로고·문구
- 교사가 선택할 때만 배경·설정·로고를 IndexedDB에 저장
- 학생 사진을 메모리에서만 처리하고 다음 모둠에서 비우는 기능
- 실제 분할과 별개임을 표시한 예시 실루엣 체험

## 사진과 네트워크

사진 업로드 서버, 외부 추론 API, 로그인, 분석 SDK가 없습니다. 앱·모델·WASM·배경은 같은 출처에서 GET으로 내려받습니다. 학생 사진·마스크·편집 기록은 IndexedDB나 localStorage에 기록하지 않습니다. 결과 PNG는 사용자가 저장한 기기의 다운로드 폴더에 남으며 앱 초기화로 삭제되지 않습니다. 다음 모둠 시작은 카메라와 Worker를 종료하고 사진 참조·실행 취소 이력·미리보기를 비웁니다.

MediaPipe Tasks Vision **1.2.3**, SelfieSegmenter square float16 **1**을 고정했습니다. Emscripten의 ModuleFactory 초기화 호환성을 위해 classic Worker와 IIFE 배포물을 사용합니다. 모델 카드와 라이선스는 `dist/vendor/NOTICE.md`에서 확인할 수 있습니다. 새 버전으로 교체할 때 모델 로딩과 실제 사진 분할을 다시 검증해야 합니다.


기능 검증 범위와 남은 검증은 [QA.md](QA.md)를 참조하세요. 실제 학교 태블릿·iPad·스마트폰 카메라, 여러 학생과 조명 조건, p95 성능 목표는 수업 도입 전에 추가 확인이 필요합니다.

## 후속 범위

인쇄 용지별 정밀 배치, 설정 묶음 전달, 검증된 오프라인 기능은 후속 범위입니다. 다인 사진을 학생별로 자동 분리하는 기능은 포함하지 않습니다.
